
# NOVA STAY - Hotel Reservation System

Web Programlama dersi kapsamında geliştirilen
full-stack otel oda rezervasyon sistemi.

## Teknolojiler
- React + Vite
- Node.js + Express (planlanıyor)
- PostgreSQL (planlanıyor)
- Socket.IO (planlanıyor)

## Temel Özellikler
- Otel ana sayfası
- Oda tipleri ve fiyatların görüntülenmesi
- Tarih ve misafir sayısı seçimi
- Rezervasyon oluşturma (planlanıyor)
- Yönetim paneli (planlanıyor)
- Anlık rezervasyon bildirimleri (planlanıyor)

## Projeyi Çalıştırma

cd client
npm install
npm run dev
